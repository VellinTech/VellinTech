# 🧠 Engineering Philosophy

I believe good software is more than code that runs.

### 01 — Understand

Know **what problem you're solving** before writing the solution.

### 02 — Design

Think about architecture, data, users and system boundaries.

### 03 — Build

Write code that is readable, maintainable and reusable.

### 04 — Test

Expect things to break. Find the failure before the user does.

### 05 — Ship

A useful product has to leave the development environment.

### 06 — Improve

Software is never really finished.

```text
BUILD
  ↓
MEASURE
  ↓
LEARN
  ↓
IMPROVE
  ↓
REPEAT
```
